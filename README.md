Banking Management System

A MySQL database project for managing branches, customers, bank accounts, account types, and transactions.

This project creates a Banking_Management_System database and demonstrates core SQL concepts including:

Database and table creation

Primary and foreign keys

Data insertion and updates

Joins

Aggregate functions

Subqueries

String, numeric, and date functions

GROUP BY, HAVING, ORDER BY, and LIMIT

Views

Transactions with COMMIT

Stored procedures

Triggers and transaction auditing

Basic database inspection commands

Database Structure

The SQL script creates the following tables:

Table

Purpose

BRANCHES

Stores bank branch information such as branch name, location, and IFSC code

CUSTOMERS

Stores customer details

ACCOUNT_TYPES

Stores supported account types, including Savings and Current

ACCOUNTS

Stores customer accounts, balances, opening dates, status, and relationships to branches/customers/account types

TRANSACTIONS

Stores deposits and withdrawals associated with accounts

Transaction_Log

Stores audit records generated when transactions are inserted

Relationships

ACCOUNTS.BRANCH_ID → BRANCHES.BRANCH_ID

ACCOUNTS.CUSTOMER_ID → CUSTOMERS.CUSTOMER_ID

ACCOUNTS.ACCOUNT_TYPE_ID → ACCOUNT_TYPES.ACCOUNT_TYPE_ID

TRANSACTIONS.ACCOUNT_ID → ACCOUNTS.ACCOUNT_ID

View

The script creates the Active_Account_Details view, combining active account information with customer, branch, and account-type details.

Stored Procedures

GetCustomerAccounts

Accepts a customer ID and returns that customer's account number, account type, balance, and status.

Example:

CALL GetCustomerAccounts(2);

GetAccountTransactions

Accepts an account ID and returns its transactions ordered by transaction date.

Example:

CALL GetAccountTransactions(101);

Triggers

Transaction_Audit_Log

An AFTER INSERT trigger on Transactions that records newly inserted transactions in Transaction_Log.

Prevent_Negative_Balance

A BEFORE UPDATE trigger on Accounts that prevents an account balance from becoming negative and raises an error when an invalid update is attempted.

How to Run

Install a MySQL-compatible database server such as MySQL.

Open MySQL Workbench or another MySQL client.

Open bms.sql.

Execute the script from top to bottom.

The script creates and selects the Banking_Management_System database automatically.

Note: The script uses MySQL-specific features such as SQL_SAFE_UPDATES, DELIMITER, SIGNAL, MONTHNAME(), stored procedures, and triggers.

Important Note

The SQL script includes test/demo statements for the triggers and transaction functionality. In particular, it attempts to update an account balance to a negative value to demonstrate the Prevent_Negative_Balance trigger. Run the script in a development/testing database rather than a production banking database.
